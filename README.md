# Power

This repository is used as a shared base for several independent, unrelated projects, each
developed on its own branch rather than merged into a single history:

- `claude/afit-studios-platform-9NWZo` - Next.js app
- `claude/hydropower-reporting-system-mwYoy` - reporting system
- `claude/pt-companion-android-0qln87` - native Android app for personal trainers/clients
- `claude/run-remote-control-9jtJy` - remote control tooling

`main` is intentionally empty and exists only as a stable, neutral base for opening pull
requests against individual project branches without mixing their unrelated histories.
